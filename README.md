# OTT Content & Platform Analytics Dashboard

## 📊 Project Overview

An interactive Power BI dashboard developed to analyze OTT content across multiple streaming platforms. The dashboard provides insights into content distribution, genre trends, country-wise title counts, content added over time, and the distribution of movies and TV shows by content rating.

## 🛠️ Tools & Technologies

- Power BI
- Data Analysis

## 📌 Dashboard Features

- Total content, movies, TV shows, and platform KPIs
- Platform-wise content distribution
- Top genres by title count
- Country-wise title count analysis
- Content added over time
- Movies vs. TV shows by content rating
- Interactive filters for exploring the data
